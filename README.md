# Overview
This repository contains the design and implementation details of an IoT Gateway, focusing on embedded microcontrollers and systems integration for process control.

# Repository Structure
- /Raspberry_Pi_Gateway  
- /Pico_W_Sensor  
- /TIA_Portal_HVAC_Simulation  
- /Grafana_Dashboards  
- /Config_Files  

# Components
- **Raspberry Pi Gateway**: The core of the IoT system that collects data from sensors and controls process actuators.  
- **Pico W Sensor**: A low-cost sensor device that connects to the Raspberry Pi for data acquisition.  
- **TIA Portal HVAC Simulation**: The software simulation environment for controlling HVAC systems.  
- **Grafana Dashboards**: Visualization tools for monitoring real-time data from the IoT system.  
- **Config Files**: Configuration files that define system parameters and settings for sensor and gateway operations.
